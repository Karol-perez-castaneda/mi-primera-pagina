## **El Software**

La parte interna intangible de las computadoras o dispositivos inteligentes se le conocé como el **Software** el cual son las introducciones internas que guían y optimizan los recursos físicos (*El Hardware*) para realizar diversas tareas en la computadora, estás se dividen en: Sistemas Operativos y los programas.

### Los Sistemas Operativos

Los sistemas operativos son software que se encarga de ejecutar los programas y crear más software, <ins>*si una computadora no tiene un sistema operativo no sirve de nada*</ins>, es por eso que es tan importante, esos se dividen en:

### Sistemas Operativos con Licencia de Uso

Estos son los sistemas operativos los cuales hay que pagar una licencia o membresía para poder utilizarlos y comparten la característica de que son de código cerrado, así que no se le pueden hacer modificaciones, entre los más conocidos están **Windows** y **MacOS**.

### Sistemas Operativos Gratuitos

Estos sistemas operativos también conocidos como sistemas operativos de código abierto, se caracterizan por ser de uso gratuito y de código abierto, lo que permite modificarlos a los gustos y necesidades del usuario, entre los más conocidos está **Linux**.

## Lenguajes de Programación

Un lenguaje de programación es una serie de carácteres, números y símbolos que permiten la conexión entre el programador y la máquina, creando un puente donde el programador puede escribir las series de instrucciones en un lenguaje que pueda entender un humano y el lenguaje de programación se encarga de pasar esas instrucciones a código binario para que lo entienda el Hardware de la computadora. 

Algunos de los lenguajes de programación más conocidos y usados son:

- Python
- C
- C++
- C#
- JavaScript
- SQL
- Java
- Ruby
- Postscript

Entre muchos otros.

> [!NOTE]
> Aunque la mayoria del tiempo se usa los lenguajes de programación mas conocidos no significa que los menos conocidos sean inferiores o peores que los conocidos, esto se debe a la estandarización por parte de las empresas, la realidad es que existen miles de lenguajes de programación pensados para cubrir diversos problemas o tareas diferente o más expecializados que los demas.

## Las Variables

Una variable es un valor o dato que guardamos en la memoria física de la computadora el cual puede ser un dígito, número, símbolo o palabra. Este valor puede ser almacenado, modificado y utilizar en un programa.

Estos valores o datos que puede tener una variable son:

- Números Enteros
- Números Decimales
- Palabras/Cadenas de texto
- Valores lógicos
