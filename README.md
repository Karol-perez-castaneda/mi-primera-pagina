# **Introducción** 

En la computación y la programación hay unos fundamentos básicos en los cuales son escenciales conocer para poder crear y desarrollar software de manera efectiva y óptima; en la **Unidad 1** del curso de **Pensamiento Algorítmico** se abarcó los temas de el Hardware y el Software, los sistemas operativos, los lenguajes de programación y que son las variables.

## **El Hardware**

Las partes físicas de los dispositivos electrónicos que componen una computadora o dispositivos inteligentes que se pueden tocar y manipular se les conocen como el **Hardware**, entre los componentes principales e indispensables para el correcto funcionamiento están:

- Gabinete
- Placa Madre/Base (Motherboard)
- CPU
- Disco Duro
- Memoria RAM
- Tarjeta Gráfica
- Fuente de Poder/Alimentación
- Unidad Óptica/de CD y/o DVD

[![fuyfi.png](https://i.postimg.cc/g2cXBbQt/fuyfi.png)](https://postimg.cc/3d6xdVK2)

### Periféricos

Son dispositivos electrónicos que permiten la comunicación exterior, ósea que la computadora reciba información o datos exteriores a la misma y viceversa, entre los periféricos existe tres tipos: de entrada, salida y mixtos.

### Periféricos de Entrada

Son los dispositivos que procesan y envían datos hechos por el usuario hacia la
computadora.

Son los dispositivos que muestran o reciben datos desde la computadora hacia el exterior.

## **El Software**

Es la parte interna intangible de las computadoras o dispositivos inteligentes se le conocé como el **Software** el cual son las introducciones internas que guían y optimizan los recursos físicos (*El Hardware*) para realizar diversas tareas en la computadora, estás se dividen en: Sistemas Operativos y los programas.

### Los Sistemas Operativos

Los sistemas operativos son software que funcionan como gestores de información los cuales dirigen y guían los recursos de la computadora, garantizando la comunicación entre Hardware y Software y entre computadora y usuario, los sistemas operativos comienzan a operar apenas se arranca la computadora y sobre ella se ejecutan los demás programas, es por eso que <ins>*si una computadora no tiene un sistema operativo no sirve de nada*</ins>, es por eso que es tan importante, esos se dividen en:

### Sistemas Operativos Comerciales

Estos son los sistemas operativos los cuales hay que pagar una licencia o membresía para poder utilizarlos y comparten la característica de que son de código cerrado, así que no se le pueden hacer modificaciones, entre los más conocidos están **Windows** y **MacOS**.

[![sistemas-operativos-comerciales.jpg](https://i.postimg.cc/65J1ZYgt/sistemas-operativos-comerciales.jpg)](https://postimg.cc/V5gRQBzV)

### Sistemas Operativos Gratuitos

Estos sistemas operativos también conocidos como sistemas operativos de código abierto, se caracterizan por ser de uso gratuito y de código abierto, lo que permite modificarlos a los gustos y necesidades del usuario, entre los más conocidos está **Linux**.

[![sistemas-operativos-libres.jpg](https://i.postimg.cc/fy35d076/sistemas-operativos-libres.jpg)](https://postimg.cc/LgpzK5bT)

### Programas

Son los software creados con el objetivo de hacer una tarea especifica, de manera sencilla e intuitiva estas se caracterizan por funcionar sobre los sistemas operativos, entre los programas más conocidos y usados estan:

- Hojas de Cálculo
- Procesadores de Texto
- Editores de Imágenes
- Editores de Video
- Programas para Desarrollar Software
- Videojuegos

Entre muchos otros.

## Lenguajes de Programación

Un lenguaje de programación es una serie de carácteres, números y símbolos que permiten la conexión entre el programador y la máquina, creando un puente donde el programador puede escribir las series de instrucciones en un lenguaje que pueda entender un humano y el lenguaje de programación se encarga de pasar esas instrucciones a código binario para que lo entienda el Hardware de la computadora. 

Algunos de los lenguajes de programación más conocidos y usados son:

## Las Variables

Una variable es un valor o dato que guardamos en la memoria física de la computadora el cual puede ser un dígito, número, símbolo o palabra. Este valor puede ser almacenado, modificado y utilizar en un programa.

Estos valores o datos que puede tener una variable son:

- Números Enteros
- Números Decimales
- Palabras/Cadenas de texto
- Valores lógicos

Ejemplo de asignación de un valor con Python

```python
k = 16
id(k)
mensaje = f"El valor de k es {k}"
print(mensaje)
```

### **Reto 1**

En ese primer reto se dio el objetivo de recrear el movimiento de la tortuga únicamente con texto, usando funciones, print() y input()

```python
# Escalon 1
cantidaddepasos1 = int (input("¿Cuantos pasos quieres que avance la tortuga hacia la derecha?"))
trazoadelante1 = "-" * cantidaddepasos1 + ">"
print (trazoadelante1) 
```
- Para definir cuantos pasos realizara la tortuga el sistema le pregunta al usuario cuantos dara la tortuga y el valor definido se guardara en el valor **cantidaddepasos1**
- Con el valor anterior definido se realiza la funcion interna **trazoadelante1** en donde el simbolo **-** se multiplica por la cantidad de de pasos definidos en **cantidaddepasos1** y se le suma un **>** al final para representar el punto donde paro la tortuga.
- Y al final se realiza la funcion de **print** para imprimir el resultado de la funcion **trazoadelante1**

### **Reto 2**

En este segundo reto se dio el objetivo de crea el rastro de la tortuga moviéndose hacia abajo usando únicamente print() e input()

```python
# Escalon 2
Abajo = "|"
Flecha = "V"
cantidaddepasos2 = int (input("¿Cuantos pasos quieres que avance la tortuga hacia abajo?"))
count = 1
while count <= cantidaddepasos2:
    print(Abajo)
    count += 1
print (Flecha)
```
- Se le define los valores **Abajo** y el valor **Flecha** con un **V**
- Para definir cuantos pasos realizara la tortuga hacia abajo el sistema le pregunta al usuario cuantos dara la tortuga y el valor definido se guardara en el valor **cantidaddepasos2**
- Se establece un ciclo **While** para imprimir el valor **Abajo** por la cantidad de de pasos definidos en **cantidaddepasos2** para simular que esta bajando la tortuga.
- Se imprime **Flecha** al final para representar el punto donde paro la tortuga.

### **Reto 4**

En este cuarto reto se dio el objetivo de usar funciones para representar los movimientos antes vistos con texto.

```python
# Escalon 1
adelante = "-"
cantidaddepasos1 = 5
espacio = adelante * cantidaddepasos1
trazoadelante1 = espacio + ">"
print (trazoadelante1) 

# Escalon 2
Abajo = "|"
cantidaddepasos2 = 3
espacio = " " * cantidaddepasos1
linea = espacio + Abajo
flecha = espacio  + "V"
count = 1
while count <= cantidaddepasos2:
    print(linea)
    count += 1
print (flecha)
```

En su base se usan los mismos valores antes establecidos y pasos a excepción de:

- En el escalon 2 se define el valor **espacio** para definir cuantos pasos ya dio hacia la derecha la tortuga para asegurar que cuando gire y camine hacia abajo si continue desde donde habia quedado antes multiplicando un espacio en blando " " por la cantidad ya dados hacia la derecha.
- Se define el valor **linea** para asegurarse que las lineas continue desde donde habia quedado antes la tortuga sumando ya los espacios en blanco definidos en el valor **espacio** y sumando el simbolo **Abajo**.
- Se define el valor **flecha** para cumplir con la misma funcion que el anterior valor pero en su lugar de **Abajo** es para poner una **V** al final para representar el punto donde paro la tortuga.
- Se establece un ciclo **While** para imprimir el valor **linea** por la cantidad de de pasos definidos en **cantidaddepasos2** para simular que esta bajando la tortuga.

### **Reto 5**

En este quinto reto se dio el objetivo de hacer que la tortuga baje en forma de escalera en el que cada escalón debe conservar la posición horizontal acumulada y dibujar correctamente tanto el tramo horizontal como el vertical.

```python
# Escalon 1
adelante = "-"
cantidaddepasos1 = 5
espacio = adelante * cantidaddepasos1
trazoadelante1 = espacio + ">"
print (trazoadelante1) 

# Escalon 2
Abajo = "|"
cantidaddepasos2 = 3
espacio = " " * cantidaddepasos1
linea = espacio + Abajo
flecha = espacio  + "V"
count = 1
while count <= cantidaddepasos2:
    print(linea)
    count += 1
print (flecha)

# Escalon 3
adelante = "-"
cantidaddepasos3 = 5
espaciototal = " " * cantidaddepasos1
espacio = adelante * cantidaddepasos3
trazoadelante3 = espaciototal + espacio + ">"
print (trazoadelante3) 

# Escalon 4
Abajo = "|"
cantidaddepasos4 = 3
espaciototal = cantidaddepasos1 + cantidaddepasos3
espacio = " " * espaciototal
linea = espacio + Abajo
flecha = espacio  + "V"
count = 1
while count <= cantidaddepasos4:
    print(linea)
    count += 1
print (flecha)
```
En su base se usan los mismos valores antes establecidos y pasos pero con ligeros cambios para que haya continuidad, se resalta el cambio:

- Apartir de escalon 3 se implementa el valor **espaciototal** donde se suman los pasos ya realizados hacia la derecha y se suman son los siguientes que se realizaran hacia esa misma direccion para asegurar la continuidad del recorrido hecho por la tortuga.
